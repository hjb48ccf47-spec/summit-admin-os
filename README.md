# Northstar OS · 行政運營平台

Northstar OS 是一個獨立於 D0133 原平台的新行政運營入口。本階段完成核心資訊架構與可部署的靜態前端基礎頁面，沿用 D0133 的柔和紙張、苔綠與卡片式視覺語言，但不共用原平台程式碼或資料。

## 第一階段範圍

- 平台總覽：健康度、待辦、活躍成員、需要留意與快速入口
- 帳號與角色權限模型：平台管理員、分區負責人、Agent 秘書、一般成員
- 分區模型：人力與文化、財務與採購、設施與安全、平台核心
- Agent／秘書入口：執行佇列、低風險助手入口與人工確認邊界
- 可配置工作台：核心、工作、協助模組與新增模組入口
- 操作手冊：平台原則、角色、分區、Agent 與後續接入路徑
- 預留 IMA 知識庫入口與低風險 AI 助手入口；第一階段不接入外部帳號、郵箱或 AES

## 本機預覽

```bash
python3 -m http.server 4173 --directory dist
```

然後開啟 http://localhost:4173。

## 部署

`dist/` 是可直接部署至 GitHub Pages、Cloudflare Pages、Netlify 或任何靜態託管服務的目錄。此版本零依賴、無建置步驟。

## 建議 GitHub 倉庫名稱

`northstar-admin-os`（推薦）或 `northstar-operations-platform`。

## 後續階段建議

1. 將角色、分區與工作項目接入持久化資料層。
2. 加入正式身份驗證與審計記錄。
3. 完成資料分級與權限映射後，再評估 IMA 知識庫連接器。
4. 以人工確認閘門包裝低風險 AI 助手能力。
